# Task 04 – To-Do List App

A simple **To-Do List** application built with **HTML, CSS, and Vanilla JavaScript/TypeScript**.

---

## Features
- Add tasks via input box  
- Display tasks in a list  
- Mark tasks as completed (strike-through style)  
- Delete individual tasks  
- Clear completed tasks or delete all tasks  
- Tasks are saved in **localStorage** (persist after refresh)  
- Includes basic CSS styling for usability  

---

## Project Structure
task_04/
