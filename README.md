Personal Profile Page — Task 02

Project Overview

This project is part of the HTML & CSS Foundation tasks.
It is a static personal profile webpage built using semantic HTML and CSS with Flexbox/Grid layouts.

The page includes:
	•	Header with name and navigation.
	•	About section introducing the student.
	•	Skills section showcasing technical skills.
	•	Projects section listing selected projects.
	•	Contact section with email, GitHub, LinkedIn, and location.

Setup Instructions

1. Clone the repository
2. Switch to the task_02 branch
3. Open the project : task_02/index.html
